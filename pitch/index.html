Project Goal

Project Goal

The goal of this project was to design and implement a responsive simple landing page using HTML, CSS and JavaScript, following modern UI/UX and accessibility principles.

The landing page simulates a real digital product and focuses on clear communication, usability, and lead generation.

Context

Why Local Reputation & SEO

Local businesses strongly depend on:

• online reviews
• visibility on maps and platforms
• customer feedback

A strong online reputation helps businesses attract new customers, build trust, and increase revenue. This project shows how a landing page can communicate these benefits clearly and support business growth.

Stack

Technology Stack & Code Organization

This project was developed using standard web technologies commonly adopted for modern static websites.

Technologies used:
• HTML
• CSS
• JavaScript
• GitHub Pages

Organization: HTML for structure, CSS for styling, JavaScript for behavior — improving maintainability and readability.

HTML

Semantic HTML Structure

The page uses semantic tags to keep structure clear and accessible: <header> for navigation, <main> for primary content, and <section> blocks for each page area.

This improves readability, supports screen readers, and makes future edits easier.

Responsive

Responsive Layout

The layout adapts to different screen sizes using:

• CSS Grid
• Flexbox
• media queries

Navigation and content are optimized for desktop, tablet, and mobile devices.

UI

Anchors & Primary Buttons

The main CTA buttons navigate users to key sections (Features / Contact) using anchor links. This supports a simple, familiar landing-page flow and helps users reach the form faster.

Buttons are designed with clear contrast and large tap targets for mobile usability.

Cookies

Cookie Consent Banner

A cookie banner is implemented to demonstrate consent UX and basic front-end interaction. The user can accept or decline, and the choice is remembered (demo behavior).

Mobile

Mobile Burger Menu

On small screens, navigation switches to a burger menu for better readability and space usage. The menu opens and closes with a clear button and improves usability for mobile visitors.

Form

Contact Form

The contact form includes required fields and client-side validation to reduce errors. This supports lead generation and keeps the interaction simple and clear.

Modal

Demo Video (Modal)

A “Watch demo” button opens a modal window with an embedded video. This keeps users on the page while offering a quick product explanation.

Deployment

Deployment on GitHub Pages

The project is deployed as a static website with GitHub Pages. This makes the landing page accessible via a public link and easy to share for evaluation.
