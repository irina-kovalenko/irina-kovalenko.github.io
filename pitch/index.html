Project Goal

The goal of this project was to design and implement a responsive simple landing page using HTML, CSS and JavaScript, following modern UI/UX and accessibility principles.

The landing page simulates a real digital product and focuses on clear communication, usability, and lead generation.

Why Local Reputation & SEO

Local businesses strongly depend on:

  • online reviews
  • visibility on maps and platforms
  • customer feedback

A strong online reputation helps businesses attract new customers, build trust, and increase revenue. This landing page communicates these benefits clearly and supports business growth.

Technology Stack & Code Organization

This project was developed using standard web technologies commonly adopted for modern static websites.

  • HTML
  • CSS
  • JavaScript
  • GitHub Pages (deployment)

Organization: HTML for structure, CSS for styling, JavaScript for behavior — improving maintainability and readability.

Semantic HTML Structure

The page is built with semantic elements such as header, nav, main, section, and footer.

This improves readability, accessibility (screen readers), and SEO, because the role of each section is clear.

Responsive Layout

The layout adapts to different screen sizes using:

  • CSS Grid
  • Flexbox
  • media queries

Navigation and content are optimized for desktop, tablet, and mobile devices.

Anchor Navigation (CTA Buttons)

The main buttons and navigation links use anchors (e.g. #features, #cta) to move users to the right section instantly.

This supports clarity and conversion: users reach key information with one click.

Lead Form & Validation

The landing page includes a contact form to capture leads. Basic client-side validation helps users submit correct data (required fields, email format).

A small message area provides immediate feedback after submission.

Cookie Consent (Demo)

The site shows a cookie consent banner and stores the user’s choice locally, so the banner does not appear again on the next visit.

This simulates a common European website pattern and improves user experience.

Mobile Burger Menu

On smaller screens, the navigation switches to a burger menu to save space and keep the interface clean.

The menu opens and closes with a button, and navigation links remain accessible and easy to tap on mobile.

Demo Video in a Modal

The “Watch demo” button opens a modal window with an embedded video. This keeps users on the page while providing product context.

The modal supports accessibility: clear close action and focus-friendly structure.
