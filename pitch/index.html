Project Goal

The goal of this project was to design and implement a responsive landing page using HTML, CSS and JavaScript, following modern UI/UX and accessibility principles.

The landing page simulates a real digital product and focuses on clear communication, usability, and lead generation through online reputation management.

Why Local Reputation & SEO

Local businesses strongly depend on:

  • online reviews
  • visibility on maps and platforms
  • customer feedback

A strong online reputation helps businesses attract new customers, build trust, and increase revenue. This landing page communicates these benefits clearly and supports business growth.

Technology Stack & Code Organization

This project was developed using standard web technologies commonly adopted for modern static websites.

  • HTML
  • CSS
  • JavaScript
  • GitHub Pages

Organization: HTML for structure, CSS for styling, JavaScript for behavior — improving maintainability and readability.

Semantic HTML Structure

The website uses semantic HTML to improve accessibility, readability, and content hierarchy. Clear elements define the role of each page section. 

<header>...</header>
<nav>...</nav>
<main>
  <section id="features">...</section>
  <section id="cta">...</section>
</main>

This structure helps both users and assistive technologies understand the page.

Responsive Layout

The layout adapts to different screen sizes using:

  • CSS Grid
  • Flexbox
  • media queries

Navigation and content are optimized for desktop, tablet, and mobile devices.

Navigation & Anchor Links

The main navigation uses anchor links to move between sections without reloading the page. It improves usability and helps users find key blocks quickly. 

<a href="#features">Features</a>
<a href="#cta">Contact</a>

Call-to-Action Buttons

Call-to-action buttons guide the user to the main actions: contacting the business and watching a demo. They support clear user flow and lead generation. 

<a class="btn primary" href="#cta">Get in touch</a>
<button class="btn ghost" id="watchDemoBtn">Watch demo</button>

Contact Form & Validation

The form collects user details and provides immediate feedback. JavaScript checks inputs and prevents empty or incorrect submissions. 

form.addEventListener("submit", (e) => {
  e.preventDefault();
  // validate name + email
});

Cookie Consent

A cookie banner is implemented with a simple logic: once the user chooses Accept or Decline, the choice is saved and the banner does not appear again. 

localStorage.setItem("cookie_consent", "accepted");
cookie.hidden = true;

Modal Window (Video Demo)

A modal window displays a short demo video without leaving the page. JavaScript controls opening and closing for a smooth user experience. 

watchBtn.addEventListener("click", () => modal.showModal());
closeBtn.addEventListener("click", () => modal.close());

JavaScript Overview

JavaScript is used to add interactivity without external libraries:

  • mobile menu toggle
  • anchor-based navigation support
  • form validation and user feedback
  • cookie consent logic (localStorage)
  • modal window for the demo video

This keeps the code simple, readable, and easy to explain line by line.
