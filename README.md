# Revvy — Local Reputation & SEO Platform  
Responsive Landing Page Project

## Project Overview
This project is a responsive landing page developed as part of the Web Design and Programming exam.

The goal of the project is to simulate a real digital product landing page, focusing on:
- clear communication
- usability
- accessibility
- lead generation

The landing page represents a local reputation and SEO platform for businesses.

## Technologies Used
- HTML (semantic structure)
- CSS (layout, responsiveness, styling)
- JavaScript (interactivity and user behavior)
- GitHub Pages (deployment)

No external frameworks or libraries were used.

## Key Features
- Semantic HTML structure (`header`, `main`, `section`, `footer`)
- Responsive layout using CSS Grid, Flexbox, and media queries
- Mobile burger navigation
- Modal video interaction
- Form validation
- Cookie consent logic with persistent user choice
- Fully responsive design for desktop, tablet, and mobile
